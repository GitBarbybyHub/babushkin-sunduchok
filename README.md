# «Бабушкин сундучок» — сайт для куратора

Домашнее задание по промпт-инжинирингу: сценарий дня рождения Кати (12 лет),
домашний квест по семейным тайнам. Сайт собирает в одном месте итоговый
сценарий, песню, разбор работы с нейросетями и все исходные материалы.

**Связка:** Gemini (цепочка промптов) → GigaChat (тексты + Kandinsky) → Suno.

## Что внутри

```
site/
├── index.html          — обзор: задача, цифры, тайминг, станции, материалы
├── scenario.html       — полный сценарий, песня, советы, иллюстрация
├── process.html        — ход работы: промпты, ошибки, скриншоты, выводы
├── assets/
│   ├── css/style.css   — оформление (без внешних зависимостей)
│   ├── js/main.js      — меню, анимации, лайтбокс, копирование промптов
│   ├── img/            — 12 иллюстраций и скриншотов
│   └── files/          — оригиналы DOCX, PDF и сопроводительное письмо
└── README.md
```

Сайт статический: ни сборки, ни npm, ни внешних CDN. Открывается двойным
кликом по `index.html` или с любого статического хостинга.

## Как посмотреть локально

```sh
# из папки site/
python -m http.server 8000
# затем открыть http://localhost:8000
```

Или просто открыть `index.html` в браузере.

## Публикация на GitHub Pages

```sh
cd site
git init
git add .
git commit -m "Сайт для куратора: сценарий «Бабушкин сундучок»"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment → Deploy from a
branch → main / (root)**. Сайт будет доступен по адресу
`https://<user>.github.io/<repo>/`.

## Что проверяет куратор

- адаптацию кейса под новые вводные (12 лет, квартира бабушки, 9 человек);
- цепочку из пяти промптов и её прохождение в GigaChat;
- самостоятельную проверку ответов: арифметика, повторы игр, картинка, тайминг;
- уточняющие промпты и их результат;
- песню в Suno и итоговый документ.
